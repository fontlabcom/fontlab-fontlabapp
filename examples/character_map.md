# Character Map grid contrast

The basic Character Map uses a white canvas for its fixed dark glyphs and coverage markers, independent of the application theme. Its typography, full BMP grid, selection, proof text and copy behavior stay the same. The official profile retains its white background and red selected-cell highlight.

Only the current paint damage rectangle is cleared. Coverage markers keep their existing blue assigned and gray missing colors. No application or widget palette, global preference or font data is changed.
