# FontLab App module map

Every Python module under `src/fontlabapp/` is assigned one primary domain.
Names are the module's explicit `__all__` or its public top-level definitions and
assignments, read from the source AST. Imported collaborators are omitted unless
the module explicitly exports them. Private modules appear here for maintenance
but are not automatically facade exports. Purposes come from module or symbol
docstrings; undocstringed modules use their source definitions. This is a
source inventory, not a native FontLab compatibility claim.

## Feature source and proof candidate

Feature Source and Proof is available through `fontlabapp.fontui.feature_proof.show(font, parent=None)`. It keeps the ordinary code view, refuses unsupported input before selection loss, and quarantines opaque document changes until explicit Revert. Accepted source Apply refreshes the independent Unicode/kerning sequence once; it does not compile or shape OpenType features. The window captures one borrowed font. External changes retain dirty drafts with a warning; explicit Apply can overwrite newer source. Refresh proof retries only the view. Original paragraph separators are inspect-only. Focused checks confirm exact UFO source preservation through the backend and editor for CR, CRLF, mixed endings and absent final newlines, including untouched siblings; duplicate feature tags are inspect-only. This candidate is not yet source-qualified; complete Fontport/App/fresh Scriptmix suites and ordinary artifact/native history/reopen qualification remain pending. Native PythonQt/FontLab, full literal paragraph-separator editing and broader clipboard routes remain unqualified.

`fontlabapp.fontui.feature_source.create_source_input` is the binding-injected source boundary used by the existing feature editor; FeatureState remains the owner of blocks and line endings. The new demo exercises this boundary through the actual source/proof window.

The optional `fontlabapp.fontui.twindow_host.Host` protocol supplies text and
owned follow notifications for TMetrics and TGlyph. `FontLabHost` binds one
font and one exact Glyph-window text block; Fontport retains explicit-layer
outline and metric transactions. Native round-trip qualification is pending.
