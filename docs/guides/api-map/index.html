    FontLab App module map

    Every Python module under src/fontlabapp/ is assigned one primary domain. Names are the module's explicit __all__ or its public top-level definitions and assignments, read from the source AST. Imported collaborators are omitted unless the module explicitly exports them. Private modules appear here for maintenance but are not automatically facade exports. Purposes come from module or symbol docstrings; undocstringed modules use their source definitions. This is a source inventory, not a native FontLab compatibility claim.
